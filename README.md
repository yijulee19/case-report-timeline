# Clinical Case Timeline Generator

A lightweight, interactive web application designed to easily visualize medical case reports, tracking patient progress, interventions, and NRS pain scores over time.

## Live App
Click the link below to view the interactive timeline and charts:
**[https://case-report-timeline.streamlit.app/]**

## Key Features
* **Dual-Tab Layout**: Neatly separates "Pre-intervention (Diagnosis)" and "Post-intervention (Follow-up)".
* **Interactive Charts**: Hover over data points to see detailed physical examination (PE) notes and NRS scores.
* **Treatment Bars**: Visualizes multiple treatment durations (e.g., Laser Acupuncture, Contrast Bath) at the bottom of the chart.
* **Event Highlights**: Easily highlight specific events (like sports competitions) with vertical shaded areas.

## Built With
